# JGVRP HUD — Minimal

Simple HUD showing vehicle metrics: speed, RPM, fuel, health, gear, and indicators.

Usage:

- Add the HUD to your page: <script src="script.js"></script>
- Update values with the exposed functions, for example: `setSpeed`, `setRPM`, `setFuel`, `setGear`, `setHeadlights`, `setLeftIndicator`, `setRightIndicator`, `setSeatbelts`.

That's it — minimal and ready.
